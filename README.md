# Qais World | عالم قيس

هذا المشروع هو منصة تعليمية باللغة الإنجليزية للأطفال، وتضم دروسًا منظمة على هيئة وحدات ومفردات، مع دعم Buddy التعليمي، والتسجيل المحلي للتقدّم، والدروس الصوتية، والألعاب.

## ما الذي يتضمنه المشروع
- ملف HTML التعليمي الرئيسي: `QaisWorld_OnePicturePerWord.html`
- واجهة Buddy لتحفيز الطفل بالدردشة القصيرة المناسبة للعمر
- تدريب نطق تقريبي على الكلمات باستخدام Web Speech API
- ألعاب تعليمية + نقاط + شارات + حفظ التقدم في `localStorage`
- دالة Vercel Serverless: `api/buddy.js` لتوصيل Buddy بخادم آمن وOpenAI API عند توفر مفتاح API

## المتطلبات الأساسية
- متصفح حديث (Chrome/Edge/Firefox) لدعم الصوت والتعرف على الكلام
- إذا أردت توصيل Buddy بواجهة OpenAI، يجب إعداد متغير بيئة على Vercel باسم `OPENAI_API_KEY`
- لا تضع المفتاح داخل HTML أو JavaScript الذي يصل إلى المتصفح

## التشغيل محليًا
### 1) افتح الملف مباشرة في المتصفح
- افتح الملف `QaisWorld_OnePicturePerWord.html` مباشرة من جهاز الكمبيوتر أو الهاتف باستخدام متصفح.
- إذا كان المشروع خادمًا محليًا، استخدم Live Server أو أي خادم بسيط مثل:

```bash
python3 -m http.server 8000
```

ثم افتح في المتصفح:

```text
http://localhost:8000/
```

### 2) تشغيل Buddy بدون OpenAI
- ستعمل الواجهة بشكل طبيعي في الوضع المحلي حتى بدون مفتاح API.
- إذا لم يتم ضبط `OPENAI_API_KEY`، ستعمل الواجهة في وضع بديل (offline) مع ردود قصيرة وقصيرة مناسبة للأطفال.

## التشغيل على Vercel
### الخطوة 1: رفع المشروع إلى GitHub
- انقل المشروع إلى مستودع GitHub جديد أو موجود.

### الخطوة 2: إنشاء مشروع جديد في Vercel
- افتح https://vercel.com
- اختر "Add New Project"
- اربط المستودع
- اترك إعدادات البناء الافتراضية

### الخطوة 3: ضبط متغير البيئة
- في لوحة Vercel، افتح Project → Settings → Environment Variables
- أضف:

```text
OPENAI_API_KEY = <your_api_key_here>
```

### الخطوة 4: النشر
- اضغط Deploy
- بعد النشر، يمكن للموقع الوصول إلى endpoint:

```text
https://<your-project>.vercel.app/api/buddy
```

## ملاحظات مهمة
- تقييم النطق في المتصفح هو تقدير تقريبي فقط؛ لا يُعد تقييمًا دقيقًا أو بشريًا.
- Buddy مناسب للأطفال، ولا يطلب أي بيانات حساسة أو شخصية.
- إذا كان الصوت أو التعرف على الكلام غير متاح في المتصفح، ستظهر رسالة نصية واضحة بدلاً من ذلك.

## أقسام المشروع

- استخدم متصفح مثل Chrome أو Edge
